# Coverage exclusions

Lines that no test reaches, and why. `make coverage` fails on any uncovered line in
`crates/*/src` that isn't matched here, and on any entry here that no longer matches
an uncovered line (so the list stays accurate). An entry matches an uncovered line in
the same file whose source text contains the quoted code.

Uncovered *functions* are the closures on these same lines (`map_err(|e| …)`,
`ok_or_else(|| …)`): llvm-cov counts each closure as a function. That is why function
coverage in `rusty_sheet` sits below 100%; the ratchet in `baseline.json` keeps it
from dropping.

## PHP built-ins failing on values the extension has already validated

The extension calls PHP's own functions for dates. These lines turn a failure of
those calls into an exception; the inputs are generated by the extension and
always valid, and the `date` extension is always compiled into PHP.

| File | Code | Reason |
|---|---|---|
| `crates/rusty_sheet/src/convert.rs` | `DateTimeImmutable::format: {e}` | `format()` with a format string that OpenSpout's converter produced; PHP's `format()` doesn't fail. |
| `crates/rusty_sheet/src/convert.rs` | `None => Ok(Zval::null()),` | `date_create_immutable()` of a wall-clock string built from a serial that `is_valid_serial` accepted; it always parses. |
| `crates/rusty_sheet/src/convert.rs` | `date_create_immutable() is unavailable` | The `date` extension is always present. |
| `crates/rusty_sheet/src/convert.rs` | `creating DateTimeImmutable: {e}` | Calling a built-in function doesn't fail. |
| `crates/rusty_sheet/src/convert.rs` | `setTimezone: {e}` | The `DateTimeZone` was created from a timezone validated in `Reader::open()`. |
| `crates/rusty_sheet/src/convert.rs` | `DateTimeImmutable::{name}() failed` | `getTimestamp()` / `getOffset()` on a valid object. |
| `crates/rusty_sheet/src/convert.rs` | `class {class} is unavailable` | `DateTimeZone` and `DateInterval` are core classes. |
| `crates/rusty_sheet/src/convert.rs` | `new {class}('{arg}'): {e}` | Constructor arguments are a validated timezone or an interval spec built by the extension. |
| `crates/rusty_sheet/src/writer.rs` | `strval() failed` | `strval()` of a float. |
| `crates/rusty_sheet/src/writer.rs` | `{method}() failed` | `format()` on a `DateTimeInterface` with a fixed format string. |
| `crates/rusty_sheet/src/writer.rs` | `unexpected date format` | The fixed format `"Y n j G i s"` always yields six numbers. |
